# Poker Coach — iPhone PWA

Mobile-first tournament poker training coach.

## Current training build
- 30-day roadmap loaded.
- Day 1 is fully playable: Big Blind Defence vs Button.
- Day 1 contains 10 chip-sized decisions.
- Visual poker-table layout and card faces.
- Short benchmark, GTO principle and practical factors after each decision.
- Progress saved locally on the device.
- PWA manifest, icons and offline service worker included.

## GitHub Pages
Upload the contents of this folder to the root of the `main` branch and publish `main / (root)` with GitHub Pages.

## iPhone
Open the live GitHub Pages URL in Safari, use Share → Add to Home Screen, and enable Open as Web App if shown.
