# Poker Coach — iPhone PWA

A mobile-first 90-day tournament poker training coach.

## Features
- 90-day curriculum
- Daily 60-minute training plan
- 6 interactive poker decision examples
- Hand-review journal
- Progress, streaks and drill accuracy
- Local browser storage
- Installable as an iPhone web app
- Service-worker offline caching

## GitHub Pages
1. Upload all files in this folder to the root of a public GitHub repository.
2. In GitHub: Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
3. Open the resulting `github.io` URL in Safari.
4. Safari → Share → Add to Home Screen → turn on Open as Web App → Add.

Keep `index.html`, `manifest.json`, `sw.js`, and the PNG icons at the repository root.

The poker examples are simplified learning scenarios, not exact solver outputs.
